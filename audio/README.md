# Real recordings (optional)

Every sound in the tour is generated in your browser (rendered once while it loads, then just played), so it works with no files. To make it sound like real recordings, put audio files in this folder with these names (`.mp3`, `.ogg` or `.wav`). Any file that is present is used instead of the generated sound:

| File | Used for |
|---|---|
| `jerusalem-ambience` | general background bed everywhere |
| `crowd` | murmur of crowds on Har HaBayis and in the courts (looped, placed in space) |
| `market` | the Pilgrim Road and plaza (looped) |
| `sheep`, `goat`, `cow` | animals being brought as korbanos |
| `birds` | birds overhead |
| `fire` | the fire of the Mizbeach |
| `flute` | the chalil of the Bikkurim procession |
| `levites` | the Leviim's song (e.g. a recording of Shir HaMa'alos / Shir shel Yom) |
| `trumpet` | the silver chatzotzros (tekiah–teruah–tekiah) |
| `music` | background music, looped, instead of the built-in violin-and-guitar niggunim |

Free sources (check each file's licence; CC0 needs no credit):
- **Freesound.org** — search "crowd murmur", "market ambience", "sheep", "goat", "cow", "pigeon coo", "campfire", "ney flute"; filter by *Creative Commons 0*.
- **OpenGameArt.org** — e.g. *Sheep Baa* (CC0) and *Fireplace sound loop* (CC0).
- **Wikimedia Commons** — category *Audio files of animal sounds*.

Works when the site is served over http (GitHub Pages), not when opening the file directly from disk.
